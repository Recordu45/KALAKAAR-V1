# Kalakaar V2 UI

Futuristic UI upgrade for the Kalakaar Music + Reels app.

Replace the existing `style.css` in the GitHub repository with this file.
The existing `index.html`, `app.js`, and `assets/wallpaper.jpg` can remain unchanged.

Highlights:
- Futuristic glassmorphism
- Neon red / violet / cyan lighting
- Animated K brand mark
- Cinematic hero
- Premium cards
- Full-screen reels feed
- Floating music player
- Futuristic creator UI
- Mobile-first responsive design
