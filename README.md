# Kalakaar V1

Music + Reels multi-user app foundation.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Current V1
- Mobile-first UI
- Home
- Reels feed
- Music discovery
- Create Reel UI
- Profile
- Initial Kalakaar branding
- User-provided wallpaper integrated as the visual background

## Planned V2
- Real authentication
- PostgreSQL/Supabase database
- Cloud video/audio storage
- User profiles and follow system
- Likes, comments, shares, saves
- Real music player
- Reel upload processing
- Admin moderation
- PWA + Android APK/AAB
